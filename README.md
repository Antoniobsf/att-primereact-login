# Tela de Login — React + PrimeReact

Aplicação web desenvolvida em React com Vite para praticar estilização com CSS tradicional combinada à biblioteca PrimeReact, incluindo interatividade no campo de senha.

## Funcionalidades

- **Estilização Híbrida:** Uso de arquivo CSS separado (`Login.css`) combinado com o tema `lara-light-blue` do PrimeReact.
- **Componentes PrimeReact:** Construção do formulário com `Card`, `InputText`, `Password` e `Button`.
- **Interatividade de Senha:** Opção de mostrar e ocultar a senha diretamente no campo através da propriedade `toggleMask` e ícones do `PrimeIcons`.
- **Validação Básica:** Verificação de campos preenchidos no envio do formulário.

## Tecnologias Utilizadas

- **React**
- **Vite**
- **PrimeReact (v10) & PrimeIcons**
- **CSS3**
